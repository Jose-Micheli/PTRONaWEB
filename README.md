# PTRONa - Landing Page

Primera versión de la landing de PTRONa.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Estructura
- index.html
- css/style.css
- js/script.js
- assets/logo/ptrona-logo.png

## Uso
Abrir `index.html` en un navegador moderno.

Los botones de descarga son marcadores provisionales y se conectarán al APK, Google Play u otro mecanismo de distribución cuando la aplicación esté disponible.
